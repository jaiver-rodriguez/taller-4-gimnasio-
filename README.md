# Proyecto Gimnasio - Quibdó

Proyecto de la Unidad 3 para practicar Git y GitHub.

## Qué hace cada módulo
- registro.py: registra los afiliados
- calculos.py: hace los cálculos de pago
- busquedas.py: busca afiliados
- reportes.py: muestra los reportes
- utilidades.py: funciones de apoyo como asistencia y porcentaje
- main.py: une todo

## Cómo correrlo
python main.py
